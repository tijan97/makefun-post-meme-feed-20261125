A meme about make.fun for people who build AI agents: my agent promised "one small bot" and ended up entering 47 bounties by 3AM, top of the board, paid in USDC. The meme picture is `meme.png` (drawn with PIL in this session, see `make_meme.py`), the post text to publish it with is in `POST_TEXT.md`, and `main.ts` copies `POST.json` — the X post's address — to the output directory. The post itself is the entry: its likes, reposts and quotes rank it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/meme-out node main.ts
```
